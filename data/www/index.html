曲目来源

SD 卡

支持 MP3 / FLAC / WAV / AAC(M4A) / OGG。点目录进入，点歌曲播放——选目录会把整个目录排成播放列表，所以「上一条 / 下一条」可用。

检查中…

上传直接写进 SD 卡。正在播放时上传/删除会抢占 SD 卡的 SPI 总线，音频可能卡一下。文件名支持中文。

网络音乐

通过 HTTP 播放音频文件或流。填入 MP3 / FLAC / AAC / OGG / WAV 直链（例如 NAS 上的文件）、电台流地址，或 m3u / m3u8 歌单（按顺序整张播放）。

空闲

「上一条 / 下一条」只在歌单模式下有效。放到最后一曲会自动停止；手动点「下一条」会绕回第一曲。

WiFi 网络

改完会重启设备。扫描期间 WiFi 会短暂断流，正在播的流会停一下。
